# Governance

## What the administrator does

Wontopos hosts the repository, keeps it running, and merges what the rules admit.

## What the administrator does not do

- Decide who is admitted. Rules 3 and 4 in the README do that.
- Merge its own submissions. They go through the same approval as everyone else's.
- Change a rule alone. Rule changes follow the same process as submissions.
- Remove a submission that meets the rules, including one that beats ours.

If any of these is violated, the licence lets you take the whole thing and run it
somewhere else. That is the actual guarantee. The rest is a promise.

## Adding a benchmark, a rule, or a result

**From a company.** Open a pull request. Three other companies with a submission
here, or with a memory product, state their agreement on it. When the third agrees,
it merges.

**From an individual.** Open a pull request. The number is not settled.

**Objections.** Any objection has to name what is wrong: a number that does not
recompute, a prompt that is not the one that ran, a rule that would admit something
unreproducible. "I disagree" is not an objection. Objections are answered in public
on the pull request.

## Conflicts of interest

Every person merging declares who they work for, in the pull request. A submission
from the same company is merged by someone else, or waits.

There is one administrator today, so this cannot be honoured for our own
submissions except by not merging them. We have submitted nothing.
Co-administrators are wanted.

## Removing something

A submission is removed if the record turns out not to support the number, and the
submitter cannot correct it. The removal, and the reason, stay in the repository.
Nothing is deleted quietly.
