# companies

One file per company, named after it. The company writes its own file: what it
builds, and its claims. Nobody rewrites another company's account of itself.

    companies/<company>.md

## Getting listed

Open a pull request that adds your file. Three other companies already listed state
their agreement on it.

## Claims

The table in each file holds numbers that are already public. None of them were
produced here.

Each row needs the model, the benchmark, the score, how many runs, the reader, the
judge, and a link to the record. A row missing the reader or the judge is still
listed, marked as such, because pretending a public claim was never made is worse
than showing what it rests on.
