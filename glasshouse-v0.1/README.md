A version is drafted by companies. This file is what it has to say before anyone can
run it.

## What a version defines

- **What it measures.** The task, and what a right answer is.
- **The corpus.** Where it comes from, how large, and how it is built.
- **The reader.** Model and settings. Submitters do not choose it.
- **The judge.** Model, settings, and the grading prompt verbatim.
- **The prompts.** The exact text given to the reader.
- **k.** How many memories a system may return per question.
- **Scoring.** The rubric, and how per-question grades become one number.
- **The harness contract.** What a submitter's harness has to do, given that it has
  to be a path a customer could use.
