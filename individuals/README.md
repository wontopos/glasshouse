# individuals

Anything that is not a company entry. Corrections, objections, recomputations,
harness contributions, a rule you think is wrong.

Open a pull request or an issue. No company has to agree for you to be heard, and an
objection that names a specific error is answered in public whoever it comes from.

The number in rule 4 is not settled.

A recomputation that shows a published number is wrong is not a proposal. It is
evidence, and it goes to the submission it disputes.
